# Deployment direction

The supplied Compose stack is the only runnable deployment. Local user accounts and RBAC now protect the API, but they do not replace production SSO, MFA, account lifecycle controls, and rate limiting. A production AWS design would use private ECS/Fargate tasks for API and UI, RDS PostgreSQL with pgvector and LangGraph checkpoint tables, a load balancer with TLS, role-based IAM, Secrets Manager, CloudWatch logs, database backups, migration jobs, and federated user access. Use separate execution and read-only investigation roles. Restrict egress, apply rate limits and request timeouts, add idempotency keys and background workers, and review infrastructure plans before apply. No Terraform module or AWS deployment automation is currently provided.
