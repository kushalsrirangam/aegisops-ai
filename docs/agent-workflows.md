# Agent workflow

The initial graph starts at triage and proceeds through investigation and knowledge. Supervisor routes to remediation if confidence is at least 0.6, otherwise escalation. Security checks the operation, target service, execution mode, risk, and action against a deny-by-default review catalog; blocked proposals escalate with a reason code in the trace. An allowed proposal reaches a native LangGraph `interrupt()` at `awaiting_approval`. PostgreSQL saves the paused graph under a stable thread ID. After a reviewer posts approve or reject, the service resumes with `Command(resume=...)` and the same thread ID. Validation writes a simulated outcome or an unverified real-mode note. The API uses `recursion_limit=16`.

This demonstrates explicit graph state, conditional edges, durable human decision resumption, and relational trace records. Runs created before this feature retain a relational-state fallback. Automatic retries, idempotency keys, background workers, and a reviewed policy engine remain open.
