# Evaluation

The deterministic sample expects the missing-column log after v2.4.1 to produce a high-confidence migration hypothesis, cited runbook, medium-risk proposal, security review, human decision, and final report. Tests assert both approval and rejection, low-confidence escalation, denylist blocking, attributed retrieval, CloudWatch metric mapping and missing-data handling, and API error behavior. GitHub Actions additionally migrates a fresh PostgreSQL database with pgvector, initializes LangGraph checkpoint tables, verifies the vector column and cosine retrieval, and checks that a fresh checkpointer can read a paused workflow before approvals, rejections, agent steps, and reports persist across database sessions. These tests do not establish semantic retrieval quality, production security, real recovery, or Bedrock accuracy. Those require separate benchmark incidents, human review, and live telemetry validation.
